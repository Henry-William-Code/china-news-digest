# Codex CLI 发布稳定版 0.167.1

- **栏目**：AI
- **来源**：[OpenAI GitHub Releases](https://github.com/openai/codex/releases/tag/rust-v0.167.1)
- **原始发布时间**：2026-11-11 05:32
- **时间说明**：GitHub 发布时间为 2026-11-10T21:32:01Z，换算为上海时间 2026-11-11 05:32。
- **时效**：最近约 24 小时

OpenAI 发布 Codex CLI 稳定版 0.167.1，对应 GitHub 标签 `rust-v0.167.1`。这是 11 月 6 日稳定版 0.167.0 之后的补丁版本，与预发布号 0.169.0 不是同一条发布线。官方发布页只给出完整变更对照链接，没有另写长篇发行说明。安装示例为：`npm install -g @openai/codex@0.167.1`。

官方 compare 页面显示该版本相对 0.167.0 超前 3 个提交，主要变更是：为常规 OpenAI Responses 路径增加可选的增量工具；将旧的增量工具限制为仅用于 Amazon Bedrock 提供方。
**为何值得关注：** 这是窗口内最新的 Codex 稳定版补丁，改动面较窄，主要面向提供方路径，不是大功能版本。
