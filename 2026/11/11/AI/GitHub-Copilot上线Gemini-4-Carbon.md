# GitHub Copilot 上线 Gemini 4 Carbon

- **栏目**：AI
- **来源**：[GitHub Changelog](https://github.blog/changelog/2026-11-10-gemini-4-carbon-in-github-copilot/)
- **原始发布时间**：2026-11-10
- **时间说明**：页面仅标注 November 10, 2026，未给出时分，不臆造具体钟点。
- **时效**：页面仅标注日期

GitHub 宣布 Gemini 4 Carbon 已在 GitHub Copilot 中正式可用，定位为复杂编程、智能体和推理任务，并强调安全代码生成与安全相关工作。该模型按提供方目录价、走按量计费。

面向 Copilot Pro+、Max、Business 和 Enterprise 用户开放，可在模型选择器中选用，覆盖 Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot coding agent、GitHub Copilot 应用、github.com、iOS/Android 上的 GitHub Mobile，以及 JetBrains、Xcode 和 Eclipse。官方称将逐步推送。Copilot Enterprise 和 Business 的管理员可通过 Copilot 设置中的模型策略管理访问；在默认模型启用规则下，新模型会自动启用，除非管理员关闭了全局默认或单独禁用该模型。
**为何值得关注：** 这是 GitHub Copilot 对同一模型的渠道落地，面向 Pro+、Max、Business 和 Enterprise，并说明将逐步推送。
