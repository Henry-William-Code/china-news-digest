# Claude 上线 Whiteboards、Sheets，并推出正式版 Claude Data

- **栏目**：AI
- **来源**：[Anthropic 官方](https://claude.com/resources/articles/sheets-whiteboards-data)
- **原始发布时间**：2026-11-10
- **时间说明**：官方介绍页未给出时分，只标日期，不臆造具体钟点。
- **时效**：页面仅标注日期

Anthropic 在 Claude 官方介绍页宣布，Claude Whiteboards 与 Claude Sheets 进入测试（beta），此前测试中的 Claude Dashboards 以 Claude Data 为名正式推出，三项功能面向所有付费方案。官方说明，Whiteboards 可供团队与 Claude 在同一块板上实时协作，例如把口头计划整理成带负责人和日期的时间线，或把复盘笔记归类并起草待办，完成后可生成文档、演示文稿，或导出到 Lucid、Miro、Vani by Zoho 等工具；Sheets 可根据提示生成含工作表、公式、格式和下拉菜单的表格，并以标记显示 Claude 的单元格改动，也可导出为 .xlsx 或 CSV。

Claude Data 在连接 Redshift、BigQuery、ClickHouse 等数据源的基础上，新增认证查询、数据叙事或解说视频、实时分享、设计系统支持、缓存与刷新周期，以及变更追踪。官方写明，其中认证查询和实时分享仍为测试。上述功能可在网页、桌面和移动端使用；Team 方案默认开启三项，Enterprise 方案中 Whiteboards 与 Sheets 默认关闭，Claude Data 计划于 2026 年 11 月 19 日默认开启，管理员可在组织设置中调整。
**为何值得关注：** 这是 Claude 把协作白板、表格和数据看板留在同一产品内的一次正式产品扩展，面向非纯编程的知识工作场景。
