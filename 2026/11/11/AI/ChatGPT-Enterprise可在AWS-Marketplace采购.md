# ChatGPT Enterprise 已可在 AWS Marketplace 采购

- **栏目**：AI
- **来源**：[OpenAI 官方](https://openai.com/index/chatgpt-enterprise-aws-marketplace)
- **原始发布时间**：2026-11-09
- **时间说明**：官方页面未给出时分，只标日期 2026-11-09，不臆造具体钟点。这与此前已经报道的 ChatGPT Businesses、Business Hub 不是同一产品事件。
- **时效**：页面仅标注日期

OpenAI 于 2026 年 11 月 9 日宣布，ChatGPT Enterprise 即日起可通过 AWS Marketplace 发现、购买和管理。官方称，企业可沿用已有的 AWS 采购和账单关系，并将符合条件的支出用于抵扣 AWS 承诺消费。在 Marketplace 上提供的能力与直接向 OpenAI 采购相同，新功能同步上线，涵盖 ChatGPT、ChatGPT Work、Codex 和 dots。OpenAI 并指出，这与已在 Amazon Bedrock 上提供的 OpenAI 模型形成互补：开发者可在 Bedrock 上构建应用，业务团队则可直接使用 ChatGPT Enterprise。

符合条件的客户还可通过 AWS Marketplace 获取 ChatGPT for Healthcare 和 ChatGPT for Financial Services。具体资格和商务条款需向 OpenAI 或 AWS 客户团队确认，官方未公布标准标价。这与此前已经报道的 ChatGPT Businesses、Business Hub 不是同一产品事件。
**为何值得关注：** 这为已经把云预算放在 AWS 的机构提供了一条官方的企业版采购和结算通道。
