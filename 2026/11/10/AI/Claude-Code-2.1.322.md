# Claude Code 发布 2.1.322，Vertex 全球及美欧区域可启用快速模式

- **栏目**：AI
- **来源**：[Anthropic（GitHub 发布页）](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)
- **原始发布时间**：2026-11-10 10:29
- **时间说明**：GitHub 发布页时间为 2026-11-10T02:29:43Z，已换算为上海时间。
- **时效**：最近约 24 小时

Anthropic 于 11 月 10 日发布 Claude Code v2.1.322。根据官方 GitHub 发布说明，该版本新增在 Vertex 的全球（global）、美国（us）和欧洲（eu）区域启用快速模式（fast mode）；若 Vertex 拒绝该请求，系统会回退到标准速度。

这是继已收录的 v2.1.321 之后的另一次版本更新。发布页列出了各平台安装包，但未再公布其他功能变更。

**为何值得关注：** 这是面向 Claude Code 企业与云上部署用户的一次可用性更新，快速模式覆盖范围扩展到 Vertex 多个区域。
