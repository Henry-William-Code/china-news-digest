# GitHub Copilot 正式上线 Claude Fable 5.2

- **栏目**：AI
- **来源**：[GitHub（Changelog）](https://github.blog/changelog/2026-11-09-claude-fable-5-2-in-github-copilot/)
- **原始发布时间**：2026-11-09
- **时间说明**：GitHub Changelog 仅标注日期，未给出时分，不臆造具体钟点。
- **时效**：约 48 小时

GitHub 在 11 月 9 日的官方 Changelog 中宣布，Anthropic 最新的 Fable 模型 Claude Fable 5.2 已在 GitHub Copilot 一般可用。该模型面向 Copilot Pro+、Max、Business 和 Enterprise 用户，可在 Visual Studio Code、Visual Studio、Copilot CLI、Copilot coding agent、GitHub Copilot 应用、github.com、GitHub Mobile，以及 JetBrains、Xcode 和 Eclipse 等环境的模型选择器中选用。官方称将逐步推送，用户若暂未看到可稍后再试。计费按供应商目录价纳入用量计费。

GitHub 同时说明，Copilot Enterprise 和 Business 的管理员须在设置中开启 Claude Fable 5.2 策略，该策略默认关闭。该模型默认需要数据留存，以便 Anthropic 运行安全分类器；GitHub 称留存数据不用于训练 Anthropic 模型。符合条件的企业客户可在日历年年底前，通过有时限的豁免以零数据留存方式使用 Fable 5、Fable 5.1 和 Fable 5.2，之后需配合 Anthropic 的 Enterprise Frontier Safeguards。获得批准后，仍须由管理员开启相应策略。

**为何值得关注：** 这是 GitHub Copilot 对 Fable 5.2 的产品接入公告，补充了计划范围、计费方式和数据留存规则，有别于模型本身的发布。
