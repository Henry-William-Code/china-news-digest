# Claude Code 2.1.321 把默认 Fable 换成 5.2

- **栏目**：AI
- **来源**：[Anthropic（GitHub 发布页）](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)
- **原始发布时间**：2026-11-10 03:22
- **时间说明**：GitHub 发布时间为 2026-11-09 19:22 UTC，对应上海时间 11 月 10 日 03:22。
- **时效**：最近约 24 小时

Anthropic 发布 Claude Code 2.1.321。这一版加入 Claude Fable 5.2，并把它设为默认的 Fable 模型，上下文 100 万 token，价格为每百万 token 输入 8 美元、输出 40 美元，缓存读取 0.20 美元。远程控制可以带上一份设置文件，文件若再改，要重启后才会用于新会话。发布说明还修了两处权限问题：MCP 的 OAuth 被重定向时，刷新令牌等秘密可能被送到另一个主机；还有一种只读 Bash 命令会在未提示的情况下跑到沙箱外面。

**为何值得关注：** 升级之后，默认的 Fable 模型换成 Fable 5.2。远程控制的新会话可以套用同一份设置文件。那两处权限修复和令牌、命令是否被拦下来有关。
