# Anthropic 发布 Claude Fable 5.2 与 Claude Mythos 5.2

- **栏目**：AI
- **来源**：[Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-2)
- **原始发布时间**：2026-11-09
- **时间说明**：官网只标注日期，没有写出时分。
- **时效**：最近约 24 小时

Anthropic 11 月 9 日宣布推出面向高难度技术工作的 Claude Fable 5.2 与 Claude Mythos 5.2。官网写明二者为同一底层模型：Fable 面向所有用户；Mythos 需通过生命科学或网络安全验证计划，供经审核的机构使用。官方称，新模型在编程、推理和视觉等方向有改进，生成速度较 5.1 最高提升约 30%，输入/输出价格为每百万 token 8/40 美元；另有可选快速模式，官方称速度最高再提升约 2.5 倍，价格为 16/80 美元。Fable 5.2 已在 Claude 各平台及亚马逊云科技、Google Cloud、Microsoft Azure 上线。文中多项基准成绩，以及“8 天写出可启动的原型操作系统”“约 30 小时完成费马大定理形式化”等，均为 Anthropic 单方表述，并非独立复核结论。此事与已收录的 Claude Code 2.1.321（把默认 Fable 切到 5.2）不是同一条：前者是模型正式发布，后者是编程工具的版本说明。

**为何值得关注：** 这是近两日最明确的一线模型发布，会直接影响 Claude Code 及云上的高难度编程与研究工作。
