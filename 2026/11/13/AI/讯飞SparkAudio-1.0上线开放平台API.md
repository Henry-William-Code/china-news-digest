# 科大讯飞星火语音基座 SparkAudio 1.0 在开放平台上线 API 服务

- **栏目**：AI
- **来源**：[讯飞开放平台（同花顺转载）](http://stock.10jqka.com.cn/20261112/c681764838.shtml)、[IT之家](https://www.ithome.com/1/026/386.htm)、[讯飞开放平台产品页](https://www.xfyun.cn/services/Spark_Audio_1.0)
- **原始发布时间**：2026-11-12 18:38；2026-11-12 21:07；2026-11-12
- **时间说明**：同花顺转载的讯飞开放平台稿标注 2026-11-12 18:38。产品页未给出精确时分。

科大讯飞 11 月 12 日宣布，星火语音基座大模型 SparkAudio 1.0 已在讯飞开放平台上线 API，开发者可直接申请调用。该模型支持文本和语音输入、文本输出，覆盖语音转写、多语言翻译、多方言识别、环境音理解、说话人分离、情感分析以及音频问答等任务。官方介绍，它不再走「先转写再交给大模型理解」的级联方案，而是直接对语音中的语义、情绪和场景进行理解，并支持 99 种语言和 202 种方言。

讯飞称，SparkAudio 1.0 基于全国产算力训练，面向智能客服、汽车座舱、跨语会议、医疗病历和内容审核等场景。与预览版相比，官方宣称整体效果提升 20%、响应时间降低 15%、成本降低 60%；这些对比和百分比均为厂商自述。讯飞还提到，面向识别场景专项微调的 Spark-ASR-2.0 已一并推出。本次可核验的核心事件是正式 API 上线，而不是更早的预览版发布。

**为何值得关注：** 这是国内主要语音厂商把通用语音基座从预览推进到可直接调用的开放 API，对需要多语言、方言和场景理解的语音应用有实际接入意义。
