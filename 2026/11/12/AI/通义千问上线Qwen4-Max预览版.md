# 阿里云百炼上线通义千问 Qwen4-Max 预览版

- **栏目**：AI
- **来源**：[阿里云百炼帮助中心](https://help.aliyun.com/zh/model-studio/qwen4-max-preview)
- **原始发布时间**：2026-11-11 10:00（UTC+8，预览期起始时间）
- **时间说明**：官方文档写明预览期为 2026 年 11 月 11 日 10:00 至 11 月 25 日 24:00（UTC+8）。页面未另给发稿时分，这里只采用文档写明的预览起始时间。
- **时效**：当前为有明确起止时间的预览版，预览结束后将下线

阿里云大模型服务平台百炼上线 Qwen4-Max-Preview。官方将其定位为通义千问新一代旗舰多模态模型，融合文本生成、图片与视频理解及深度思考，适用于编程开发、办公、前端设计与复杂智能体任务，并支持联网搜索、工具调用和结构化输出，兼容 OpenAI 与 Anthropic API。模型 ID 为 `qwen4-max-preview`，上下文长度为 1M Token，最大输出长度为 393,216 Token，思考内容与最终回答共享该输出预算。

当前仅为预览版，只支持 Token Plan，不支持按量计费；预览期内不做变更，结束后将下线。思考模式默认开启，可通过 `reasoning_effort` 在 low、medium 或 xhigh（默认）之间调节，且不能与 `thinking_budget` 同时设置。接入需使用 Token Plan 专用 API Key 和北京地域套餐 Base URL。

**为何值得关注：** 这是千问新一代 Max 旗舰的公开预览窗口，档期和接入方式已写入官方文档，预览将在 11 月 25 日结束。
