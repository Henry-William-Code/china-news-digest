# MiniMax 发布并开源图像生成模型 H3-Image

- **栏目**：AI
- **来源**：[MiniMax 官方博客](https://www.minimax.io/blog/minimax-h3-image)
- **原始发布时间**：2026-11-11
- **时间说明**：官方博客标注 2026-11-11，未给出时分。文中写 Today, we're releasing MiniMax H3-Image。
- **时效**：权重已开放，官方服务同步可调用

MiniMax 发布开源权重图像生成模型 MiniMax H3-Image，基于 H3 构建，支持文生图、参考图生成和图像编辑。官方称其可在 10 秒内生成一张 4K（4096×4096，约 16MP）图像，最多支持 16 张参考图，并称在开源权重模型中具有较强的指令遵循能力；与「主流方案」相比的速度优势为厂商自述，页面写的是最高可达约 5 倍。模型权重已经开放，也可通过 MiniMax API 平台、MiniMax Code 和海螺（Hailuo AI）调用生成服务。

官方称 Standard 模式速度约为其所称主流方案的 1.5 至 2 倍，Highspeed 模式约为 3 至 4 倍，服务定价约为同档位方案的 50% 至 70%；发布首周，4K 及以上规格的生成请求可按官方定价五折计费。上述速度和比价表述来自官方披露，不是独立评测结论。

**为何值得关注：** 开源图像模型同时给出 4K 生成、多图参考和可调用的官方服务，是窗口内一次完整的产品更新。
